# Identificador de Plantas

Projeto para publicar na Vercel e usar a API do Pl@ntNet.

## Variável obrigatória

Na Vercel, em Settings > Environment Variables, crie:

PLANTNET_API_KEY = sua chave privada do Pl@ntNet

Depois faça um novo deploy.

## Uso

A página principal fica em `/`.
No Canva, coloque o endereço publicado pela Vercel no botão que abrirá o identificador.

A chave da API não fica no navegador.
